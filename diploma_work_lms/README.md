# Modern tanulásmenedzsment rendszer

Webalapú tanulásmenedzsment rendszer hallgatók és oktatók számára. Az alkalmazás egy helyen kezeli a tárgyfelvételt, a kurzusanyagokat, a vizsgajelentkezést, az előrehaladást és az oktatói adminisztrációt.

## Főbb funkciók

- tárgyak és kurzuscsoportok felvétele, leadása;
- kurzusanyagok megtekintése és kezelése;
- vizsgajelentkezés és jegykezelés;
- tanulmányi előrehaladás és ütemterv megjelenítése;
- Gemini-alapú kurzusösszefoglaló és tanulókártya-generálás;
- szerepköralapú hallgatói és oktatói felület.

## Technológiák

React, React Router, TypeScript, Tailwind CSS, shadcn/ui és PocketBase. A kliensoldali alkalmazás a `canvas_client_react_router` projektben, a PocketBase háttérszolgáltatás a `canvas_server_pocketbase` projektben található.
